# Discord cleanup pilot

Archived KernelSU module for `PLR110_16.0.10.500(CN01)`. It adds a native Athena
`use_kill` exception for Discord while preserving the original custom policy.
Requires Mountify in automatic mode.

Use the current module at the repository root for user-app coverage and the
companion app. Both versions share the same module ID.

To build this archive, run `python3 build.py` in this directory.
